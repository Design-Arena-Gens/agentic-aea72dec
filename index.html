Mission:

Launch a modern WordPress experience that converts demo requests and paid projects.

Master Execution Prompt

Paste this prompt into your build workflow (e.g., AI pair-programmer, internal SOP, or agency ticket) to produce the full WordPress site.

Primary Objective

Architect and launch aayamarts.com on WordPress as a premium digital showroom for Aayam Arts, specializing in 3D walkthroughs, blueprints, building elevations, VR demos, and 3D prints for residential and commercial complexes, apartments, and housing societies.

Core Requirements

  1. Deliver a lightning-fast, responsive, SEO-ready WordPress site using a modern visual builder (Elementor Pro or Gutenberg blocks with a lean base theme such as Hello or GeneratePress).
  2. Integrate all supplied media assets (images, renders, videos, CAD snippets) into a visually rich portfolio that highlights service depth, innovation, and successful outcomes. Create custom thumbnail covers if any asset lacks a poster frame.
  3. Ensure every non-hero section includes a high-visibility CTA button or sticky action (Book a Demo, Buy a Service, Request Custom Quote).
  4. Build an intuitive navigation and user journey that funnels visitors from awareness to conversion in three clicks or fewer.

Page Map & Content Blueprint

  • Homepage: Immersive hero with background video loop (web-optimized portfolio footage), USP headline, trust proof ribbon, and dual CTAs. Add dynamic counters (projects delivered, satisfied clients, total built-up area visualized) with GSAP-like animations.
  • Services Hub: Break down offerings into modules for 3D Walkthroughs, 3D Blueprints, Architectural Elevations, VR Demo Studios, and 3D Printing. Each module must showcase use cases, feature highlights, mini galleries, pricing tiers (if available), and context-specific CTA (e.g., “Start Elevation Design”).
  • Portfolio Vault: Grid and filterable showcase using categories (Complexes, Apartments, Societies, Commercial). Each project detail page includes hero media, challenge/solution/outcome narrative, embedded walkthrough (YouTube/Vimeo/MP4), gallery slider, and testimonial pull-quote.
  • Process & Tech Stack: Timeline layout describing discovery, concepting, modeling, rendering, iteration, delivery, and aftercare. Highlight software stack (AutoCAD, Blender, Unreal, Unity, proprietary pipelines) and include a “Book Your Process Demo” CTA ribbon.
  • Industries & Use Cases: Segment by Residential, Commercial, Urban Planning, Hospitality, and Retail. For each, outline value props, deliverables, and tailored CTA.
  • Insights Blog: Activate WordPress blog with at least six pillar posts (e.g., “How 3D Walkthroughs Accelerate Sales for Apartment Builders”) scheduled for publication. Optimize with internal linking, schema, and rich snippets.
  • Contact & Conversion: Multi-step form (Name, Email, Phone, Organization, Project Type, Timeline, Budget, Upload Brief). Integrate Calendly (or similar) for instant demo bookings and embed a WhatsApp floating action button.

Design Direction

  • Color System: Midnight charcoal (#0f172a), electric cyan (#06b6d4), warm accent amber (#f59e0b), off-white backgrounds (#f8fafc).
  • Typography: Pair a bold geometric sans for headings (e.g., Gotham, Montserrat) with clean body copy (Inter or Source Sans). Ensure ample white space and cinematic media presentation.
  • Use layered glassmorphism cards, subtle parallax, and hover microinteractions. Keep animations GPU-friendly and non-intrusive.
  • CTA buttons must be sticky on mobile, and desktop header should feature a “Book a Demo Now” high-contrast button.

Functional Must-Haves

  • Compress and lazy-load all media. Serve videos via native HTML5 players or trusted embeds with custom poster frames. Ensure WebP conversion for images.
  • Implement caching, CDN, and performance plugins (WP Rocket or equivalent). Target sub-2s LCP on mid-tier mobile devices.
  • Configure analytics (GA4), conversion goals, and event tracking for all CTAs, forms, and media engagements.
  • Add GDPR-friendly cookie banner, privacy policy, and terms pages.
  • Secure the site with SSL, reCAPTCHA v3 on forms, and daily backups.

Portfolio & Asset Handling

  • Upload all supplied imagery/video into WordPress Media Library with descriptive alt text and filenames. Organize using folders (via plugin if needed) by service type.
  • For each case study, craft a storytelling narrative, client persona, scope, deliverables, tools used, timeline, challenges, solutions, and measurable outcomes (conversion lift, sales velocity, cost savings).
  • Build an interactive gallery modal with autoplay toggle, VR demo embeds, and download option for PDF blueprints.

Marketing Integrations

  • Connect marketing automation (HubSpot/ActiveCampaign) for lead capture, nurture sequences, and CRM syncing.
  • Implement exit-intent popup offering “Free 3D Visualization Audit”.
  • Add testimonial carousel with client logos, ratings, and video snippets. Include trust badges (ISO, RERA, awards) if available.
  • Create downloadable brochures/one-pagers gated behind lead capture forms.

SEO & Content Governance

  • Perform keyword mapping: primary (3D walkthrough services India, architectural visualization studio), secondary (VR property tours, building elevation designers), and local queries (3D visualization in Pune/Mumbai/etc.).
  • Configure Yoast or Rank Math with tailored metadata, schema markup, and Open Graph images. Implement breadcrumb navigation.
  • Draft cornerstone content style guide to maintain tone (expert, visionary, solution-driven) and brand voice consistency.

Launch Checklist

  • Cross-browser QA (Chrome, Safari, Firefox, Edge, Android, iOS).
  • 404 page customization with CTA redirecting to demo booking.
  • Performance audit via PageSpeed Insights and WebPageTest.
  • Accessibility: WCAG AA checks, focus states, ARIA labels.
  • Security hardening: limit login attempts, disable XML-RPC if unused.

Post-Launch Handoff

  • Document full component library, global styles, and WordPress admin training guide (video + PDF).
  • Provide 90-day maintenance plan with update cadence and analytics reporting.
  • Include roadmap for future enhancements: interactive cost calculator, AR visualization previews, client portal.
